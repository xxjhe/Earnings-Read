# 七层框架财报解读

用《财务报表分析与股票估值》七层流水线解读单一标的财报，输出自包含 HTML 报告。

## 调用名与调用方法（防混淆设计）

**主调用词：「财报七层」**。最简用法：`财报七层 阳光电源` / `财报七层 300274`。

命名意图：**「财报」二字划定边界——本技能只做财务报表分析**（报表质量、主业盈利、资产负债结构、现金流、价值创造），不做业务、行业、竞争格局、估值定价分析；「七层」指 L0-L6 判读流水线。

| 触发词 | 类型 | 说明 |
|---|---|---|
| **财报七层 XX** | 主调用词（推荐） | 「财报」锚定纯财务边界，「七层」指 L0-L6 |
| 财报七层解读 XX | 完整形式 | 语义最完整 |
| 七层解读 XX | 兼容别名 | 简短说法 |
| 框架 / 解读 XX | 框架词 | 以方法论命名 |
| GYQ解读 XX | 缩写速记 | 键盘最快 |

**边界（读到这些词不要误触发本技能）**：

| 请求类型 | 区别 |
|---|---|
| 本技能 | 单一标的**纯财务报表分析**：财报质量、主业盈利、资产负债结构、现金流、价值创造 |
| "财务分析 XX" / "跑一下模型" | 仅跑引擎出全指标 HTML，不做七层判读 |
| 业务/行业/竞争格局/估值买卖点问题 | 财报之外的问题，不归本技能；发现的业务侧疑点只写入跟踪点，不展开 |

**动手前必读**：方法论主文件 HTML + 至少一份范例报告。不要在未读的情况下凭记忆写七层结构。

## 环境准备（首次使用）

- Python 3.10+，依赖安装：`pip install -r requirements.txt`（pandas / numpy / requests / akshare）。
- 默认数据源为 akshare（东方财富公开接口，免 token）；可选 tushare（需自行提供 token）。

## 执行流程

### 1. 确认标的身份（先做，别跳）

核对全称/代码/上市板。**历史上踩过坑**：用户说"龙创设计"，实为新三板 832954.NQ（非 A 股）。标的搞错，后面全废。

### 2. 选数据通道（关键分叉）

| 标的类型 | 通道 | 方法 |
|---|---|---|
| 沪深 A 股 / 北交所 | **finmodel 引擎** | 在 `engine/` 目录下执行 `python fin_analyze.py <公司名或代码>`，读 `output/<code>_annual.csv` 与 `_quarterly.csv` |
| **新三板**（43xxxx/83xxxx/87xxxx/92xxxx） | 引擎不支持（已实测），用环境内可用的财务数据源（Wind / Choice / 同花顺 iFinD 等）取三表科目 + 上市板/主营构成；无数据源则手动汇编年报 | 按报告期分组批量要科目（一次请求 20-30 个科目），比逐个取快得多 |
| 全部通道失败 | WebSearch / 公开年报手动汇编 | 需在报告显著标注数据来源与口径局限 |

**手动汇编要点**：务必在报告页首加"平台前提"警示框，说明数据为手工录入、可能与最新披露存在时滞。

### 3. 逐层判读（七层，缺层须写明原因）

- **L0 财报质量门禁**：审计意见 / 关键审计事项 / 非经常占比 / 净现比 / 收现比 / 减值行为 / 勾稽误差。任一触发门禁规则 → 降信级并写入红旗。
- **L1 战略识别**：毛利率 × 周转 × 费用结构 → 成本领先 or 差异化；**服务业必须补人效**（营收/员工数、人力成本占营收比）。
- **L2 资产资本表**：钱投在哪（金融资产/营运资本/长期经营资产/长投占比）→ 钱从哪来（有息负债率/财务杠杆/无息占款/权益）→ 期限匹配（长期融资净额、营运资本长期化率）。
- **L3 股权价值增加表**：阶段利润1 → 阶段利润2 → 息税前经营利润 → **剥离金融收益看主业纯度**（经营利润占比）。
- **L4 ROE 五因素归因**：见下方口径。三选一判定 A 主业/B 杠杆/C 非经营；**B 类必须配 ROIC vs 税后债务成本检验**。
- **L5 现金流三表**：经营（含金量）→ 投资（战略落地）→ 筹资（资本管理）→ 八分类定位 + **风格迁移路径**。
- **L6 价值评估**：ROIC vs 股权成本 10% / EVA / FCF 三问。

### 4. 产出报告

文件名 `<公司名>_框架解读.html`，结构与范例一致：header → 一句话结论(tldr) → KPI 卡片 → L0~L6 各一段（h2 的 tag 内放该层结论）→ 红旗清单与跟踪条件 → footer（口径说明 + 数据缺口 + 免责声明）。

**纯 HTML+CSS，不加 ECharts**（表格是框架的天然表达方式）。

### 5. 必做数据自检（不可省）

写完报告后，用脚本复算关键指标，重点验：**五因素连乘是否等于"净利润/股东权益"**。不等则口径有误，须查 ③。

```bash
python -c "复算 f1*f2*f3*f4*f5 与 np/equity 对比"
```

## 关键口径定义（照抄，否则算不平）

```
息税前经营利润   = 利润总额 + 财务费用 − (投资收益 + 利息收入)
息前税后经营利润 = 息税前经营利润 × (1 − 实际税率)      实际税率 = 所得税 / 利润总额
① 息税前经营利润率 = 息税前经营利润 / 营业收入
② 资产周转率      = 营业收入 / 资产总额
③ 财务成本效应    = 利润总额 / 息税前经营利润     ← 关键：分母是"息税前经营利润"，不是 EBIT
④ 财务杠杆倍数    = 资产总额 / 股东权益
⑤ 所得税效应      = 净利润 / 利润总额
ROE = ①×②×③×④×⑤   （须与 净利润/股东权益 吻合，用于自检）
营运资本(净)   = (应收票据+应收账款+其他应收款+预付款项+存货+合同资产) − (应付票据+应付账款+合同负债+应付职工薪酬+应交税费)
长期经营资产   = 固定资产 + 在建工程 + 无形资产 + 长期待摊费用
有息负债       = 短期借款 + 一年内到期的非流动负债 + 长期借款 + 租赁负债
ROIC = 息前税后经营利润 / (有息负债 + 股东权益)
EVA  = 净利润 − 股东权益 × 10%（股权成本假设，可调）
FCF  = 经营活动现金流净额 − 购建长期资产支付的现金
净现比 = CFO / 净利润      销售收现比 = 销售商品提供劳务收到的现金 / 营业收入
```

## 避坑

1. **③ 财务成本效应别写成 /EBIT** —— 用 EBIT 做分母五因素连乘算不平（含金融收益加减，必须用息税前经营利润）。
2. **营运资本为负时"营运资本长期化率"失真**（分母为负）——改看占款模式可持续性（合同负债/应付账期），并在报告标注"⚪ 指标失真"。范例博力威、龙创设计均遇此情形。
3. **债务成本过低要警惕利息资本化** —— 若"利息费用/有息负债"显著低于市场利率（如在建工程大），可能存在资本化，须标注"估算值，需核验"。
4. **任何进报告的中间值都要脚本验证** —— 曾凭估算把长期经营资产占比填错（24.5% vs 实际 27.2%）。**估算值必须落脚本，不能凭手算填表**。
5. **ROE 提升的归因要诚实** —— 逐因子算贡献倍数并排序，杠杆是第一贡献者时必须明说，不能因利润率/周转也在改善就笼统归为"主业驱动"。
6. **框架外的重要约束不能省** —— 如新三板的流动性/无估值锚问题，应在结论与红旗清单中明确点出（价值结论无法二级市场兑现）。
7. **区分"价值"与"价格"** —— L6 的结论只描述财务质量；能否买到、以什么价格买到是独立问题。
8. **口径不一致的年份要标注** —— 半年报未年化，与年度数据不可直接比（② ③ ⑤ 受影响）。
9. **季度版 EVA/剩余收益/ROCE 不可比** —— 股权成本未按季折算（单季利润减全年 10% 成本），恒为大额负数，**解读只用年度值**；阳光电源范例已踩点注明。
10. **巨额理财滚动会放大现金口径勾稽误差**（如阳光电源年 800 亿滚动，误差 -12.5 亿）——这是模型重建近似差，不是舞弊信号，但要在 L0 注明。
11. **收入断崖期看存货要用"季度同口径环比"**（季度天数公式是 360/单季成本，绝对值约为年度 4 倍，只能同口径比方向）；量/价贡献拆分是判断"以价换量 vs 结构升级"的核心证据。
12. **主业利润下滑时金融收益占比会被动升高**（分母效应）——不是经营恶化信号，但要提示读者回到息前税后经营利润口径看主业。

## 报告末尾固定三段

1. **口径与数据来源说明**：数据源 + 交叉核对值 + 计算方式（引擎 or 手动复算）+ 五因素自检结果 + 假设（股权成本 10%）+ 关键科目口径定义。
2. **数据缺口**：未取得的项（不推测）。
3. **免责声明**（固定文案）：
   > 以上内容基于公开数据和量化分析，仅供参考，不构成投资建议。市场有风险，投资需谨慎。任何投资决策应结合个人风险承受能力、资金状况和投资目标独立判断，必要时咨询持牌专业机构。过往表现不预示未来收益。
