# 财报解读 Skill

基于《财务报表分析与股票估值》方法论封装的 AI Agent 技能（Skill）：对单一上市公司财报做 **L0-L6 七层流水线判读**，产出一份自包含的 HTML 深度解读报告。

**纯财务报表分析**——只回答"这家公司的报表质量、主业盈利、资产负债结构、现金流、价值创造怎么样"，不做业务、行业、竞争格局、估值定价分析。

## 七层框架一览

| 层 | 内容 |
|---|---|
| L0 财报质量门禁 | 审计意见、非经常占比、净现比/收现比、减值行为、勾稽误差 |
| L1 战略识别 | 毛利率 × 周转 × 费用结构 → 成本领先 or 差异化 |
| L2 资产资本表 | 钱投在哪、钱从哪来、期限是否匹配 |
| L3 股权价值增加表 | 剥离金融收益，看主业利润纯度 |
| L4 ROE 五因素归因 | 主业 / 杠杆 / 非经营 三选一判定 |
| L5 现金流三表 | 经营含金量、投资战略落地、筹资资本管理 + 八分类定位 |
| L6 价值评估 | ROIC vs 股权成本、EVA、FCF 三问 |

## 目录结构

```
财报解读/
├── SKILL.md                 # 技能主文件（Agent 加载后按此执行）
├── requirements.txt         # 引擎 Python 依赖
├── references/              # 方法论与范例（动手前必读）
│   ├── 公司财务解读分析框架_融合版.html   # 方法论主文件（七层定义+阈值+模板）
│   ├── 范例_博力威_框架解读.html           # 格式基准（困境反转类）
│   ├── 范例_阳光电源_框架解读.html         # 范例：周期逆风背离写法
│   └── 范例_龙创设计_框架解读.html         # 范例：新三板手动汇编
└── engine/                  # 财务指标引擎（A股/北交所）
    ├── fin_analyze.py
    └── finmodel/
```

## 安装

1. 将整个 `财报解读/` 文件夹复制到你的 Agent 技能目录：
   - **WorkBuddy / CodeBuddy**：`~/.workbuddy/skills/`
   - **Claude Code**：`~/.claude/skills/`
2. 安装引擎依赖（只需一次）：

```bash
pip install -r requirements.txt
```

3. 重开会话（或重启 Agent），即可用触发词调用。

## 使用

对 Agent 说：

```
财报七层 阳光电源
财报七层 300274
用框架解读 博力威 的年报
GYQ解读 宁德时代
```

输出：`<公司名>_框架解读.html`（自包含单文件，浏览器直接打开）。

也可以单独使用引擎（复现 Wind 财务分析模型全指标）：

```bash
cd engine
python fin_analyze.py 博力威                    # akshare/东方财富（免token）
python fin_analyze.py 688345.SH                 # 按代码调用
python fin_analyze.py 博力威 --source tushare --token <TOKEN>
```

引擎产出 `报告二_<公司名>_财务分析解读.html` 及 `output/<code>_annual.csv / _quarterly.csv` 全指标明细，供七层判读引用。

## 数据源说明

- **沪深 A 股 / 北交所**：引擎默认走 akshare（东方财富公开接口，免 token），可选 tushare。
- **新三板等引擎不支持标的**：需自备财务数据源（Wind / Choice / iFinD）或按年报手动汇编，报告中须显著标注数据口径局限。
- 引擎不内置任何密钥；如用 tushare，token 由使用者自行通过参数或环境变量 `TUSHARE_TOKEN` 传入。
