# Kimi Work Skills 仓库

由 Kimi Work 生成和维护的自定义 skill 集合，每个 skill 存放在独立的子目录中。

## Skill 目录

| Skill | 说明 | 上传日期 |
|-------|------|----------|
| [财报解读](财报解读/) | 基于《财务报表分析与股票估值》方法论的七层财报解读框架：对单一上市公司财报做 L0-L6 七层流水线判读，产出自包含 HTML 深度解读报告 | 2026-10-21 |

## 安装方法

把对应 skill 文件夹（如 `财报解读/`）复制到你的 Agent 技能目录：

```
用户级（所有项目可用）: ~/.workbuddy/skills/<skill-name>/
项目级（仅当前项目）:   <项目>/.workbuddy/skills/<skill-name>/
```

各 skill 目录内均有独立的 `README.md`，包含详细使用说明和触发词。
